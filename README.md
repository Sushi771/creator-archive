# Creator Archive 0.6.0rc10 预览

源码界面已精简为“阅读 / 下载与任务 / 设置”：左侧全部订阅可筛小红书或公众号，选择博主后阅读本机作品；正文与图片视频优先，指标及技术ID收进高级详情。顶部添加订阅，当前博主更新/下载范围明确，全部订阅操作单独展开；账号、保存位置、外观与更新频率归设置。管理页切换平台或标签后重新勾选。下载复用本机导出，不访问平台；订阅保留原默认前三篇及原有最多30篇选项。公众号已有资料保留，真实验收暂缓。

账号采用一个独立本机会话：本人扫码确认 → 非guest账号身份核验 → 原子保存会话及旧会话备份；作者第一页在订阅同步时另行核验。普通浏览器登录不等于应用接入成功。既有真实记录包含HTTP471及详情HTTP302跳转到登录页，具体认证原因仍未知；rc10记录初始化、二维码、扫码确认和身份核验阶段，重启保留脱敏错误。不要反复扫码；没有实质修复或条件变化，不重复失败请求。

正常同步首次及刷新都只读取最新第一页，最多30篇；前三篇仅是当前本人抽查范围。正文、图片、视频、本机导出分别计数，不声称全部历史。验证/限流/HTTP/业务失败停止当次任务，不自动重试、不跟跳转、不导入普通浏览器会话、不浏览器采集回退。定时关闭，旧任务不自动恢复，无额外许可、作者白名单或人工硬暂停。真实账号及内容闭环未通过，仍为预览版。

Windows包是Python源码预览，需Python3.11+。install.cmd设置桌面Start / Stop / Files；Start打开 http://127.0.0.1:8765/，Stop停止，Files打开实际归档位置。已有安装通过upgrade.ps1升级；SQLite backup及quick_check后保留旧程序、数据库、媒体、任务及手工资料。会话仅存私有workspace，不提交或发送聊天。本轮未升级或重启安装，新界面仅在源码分支；历史安装为rc10，实际源码/安装差异见[PROJECT_STATUS](PROJECT_STATUS.md)。模拟截图及复验步骤见[技术验证文档](docs/03_双平台内容归档_技术设计与验证.md)。

## 启动与使用

Windows 首次双击 [install.cmd](install.cmd) 建立桌面入口，再双击 **Creator Archive - Start**；首次启动自动建立 Python 环境并安装固定依赖，打开 [本机工作台](http://127.0.0.1:8765/)。需要 Python 3.11+；本轮用 Python 3.14.0 验证。桌面 **Stop** 停止，**Files** 打开当前归档根；`start.cmd`/`stop.cmd` 仍可直接使用。详细步骤见[运行说明](docs/07_验证骨架运行与接口.md)。

网页链接需要本机服务正在运行；打不开时先运行最新工作树的 `start.cmd` 或桌面 Start。已有快捷方式可用 `install.cmd` 更新为当前工作树入口；安装时自动记住资料与运行目录。卸载用 [uninstall.cmd](uninstall.cmd)，保留资料和路径记录；重装须使用同一程序目录，若移动程序目录则在安装时显式指定旧工作区。

1. Start打开工作台后，在“历史与任务”查看42/43的前10篇归档与46/47的指标重读，均各10/10；“作品资料库”查看最新指标和快照，到作者“打开归档”读取原离线结果，已完成不用再次新建。
2. 需要新的最小测试时点“测试各作者前10篇”，或某作者“测试前10篇并归档”。仅已核验且已确认的小红书作者纳入；失败只恢复原任务未完成项。
3. “作品资料库”可按作者、日期、类型和互动指标筛选。未知指标不算0；本轮20篇的点赞/收藏/评论60字段中25有值、35未知，保留来源与观察时间。
4. Files打开原归档；完整历史/全部已收录内容操作位于折叠“完整归档实验（超出本轮10篇测试）”，本轮不需要运行。
5. 添加作者与确认订阅不自动扫描历史。待确认作者须由用户决定，公众号暂不进入本轮。

数据默认保存在 `%LOCALAPPDATA%/CreatorArchive/workspace/`，归档在其 `archive/`，运行日志位于 `CreatorArchive/runtime/`。Codex Windows 环境可能将该路径解析至应用的 `LocalCache/Local`，以页面显示的绝对路径为准。旧验证资料与 WeWe 部署不变。
