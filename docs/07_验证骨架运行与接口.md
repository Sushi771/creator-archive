## 启动

已测试 Windows + Python **3.14.0** + SQLite **3.50.4**。在仓库根目录 PowerShell 执行：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.lock
.venv/Scripts/python.exe -m creator_archive
```

打开 `http://127.0.0.1:8765/`。完成首次安装后，也可执行 `./start.ps1`。Ctrl+C 停止；不用修改 PowerShell 安全策略。端口占用时先停止本项目旧进程，不随意结束其他程序。没有安装包、自启动或公网服务。

本轮已在本机建立 `.venv`，正常再次运行只需最后一条命令。服务不联系平台、不读浏览器会话；使用 `data/validation/state.sqlite3` 保存自造作者/作品 ID、逐页证据和检查点。该目录被 Git 排除，不保存真实正文、媒体或用户笔记。当前根目录在 OneDrive 下，因此后续真实敏感状态应另选用户认可的非同步目录，本轮仅写模拟数据。

## 可验收操作

1. 输入公众号文章/主页、小红书作品/主页/短链或含单个链接的分享文本，点击检查。仅分类并可给出候选 ID；始终返回身份未核验，不能建立真实订阅。分享参数不写入数据库或返回响应。
2. 点击“运行模拟并注入故障”：四位自造作者（两平台各两位），每位四页、60 个唯一 ID，后三页含置顶重复。两个 A 作者完成；公众号 B 与小红书 B 在第 3 页前分别进入 needs_login 和 rate_limited，保留 2 页/30 个 ID。
3. 点击“移除模拟故障并继续”：公众号模拟重新登录后继续；小红书必须经过 5 秒冷却再继续，重复点按钮不绕过冷却。成功后四位均为 4 页/60 ID；正文与媒体仍显示未实测。
4. 关闭并重启服务、刷新页面，检查点仍在。已完成模拟任务重复点击复用结果，不重新注入故障。需要重演时，可在停止服务后将 `data/validation` 改名保留为备份，再启动生成新数据；不要对真实档案套用此操作。

“暂停订阅”只是固定模拟范围中的一个样本标签，用于验证批次不因标签漏作者，尚未实现真正的订阅暂停/取消功能。

## HTTP 接口（仅实验，不是最终产品 API）

| 路由 | 行为 |
| --- | --- |
| GET `/api/status` | 版本、validation_only、g1_passed=false、两平台尚未接入的能力、模拟检查点 |
| POST `/api/links/classify` | `{text}` → 平台、链接类型、候选 ID、identity_verified=false、can_subscribe=false；错误422 |
| POST `/api/demo/run` | `{inject_failures: true/false}` → 固定四位模拟作者的逐源结果；运行中返回409；不会访问平台 |

POST 要求 `X-Creator-Archive: local-validation`，有 Origin 时须与本服务一致；不开放跨域。Host 只接受本机主机名（`testserver` 仅供测试）；绑定回环、无访问 URL 日志、CSP 禁止外部脚本和嵌入。这个请求头是跨站操作防护，不是生产身份认证。本版只存模拟数据；接入真实资料前须补配置目录与认证。

## 持久化合同

- Store 创建独立 SQLite 连接并确定性关闭。平台/作者是运行唯一键，平台/作品是内容唯一键。
- 一页的作品与下一游标、请求游标、ID 集合、末页依据、观察时间在同一事务提交，随后才请求下一页。进程在提交后退出可从下一游标恢复。
- 检查页级身份和已有作品归属；发现冲突整页回滚，不能把作品移动到另一个作者。
- has_more 必须为布尔值；完整必须有明确末页证据且无下一游标。空页但仍有下一页、缺游标、循环游标、上限、错误均不能标完成。
- 401 类错误要求明确恢复；429 类错误的冷却时间持久化；超时保留失败页。适配器版本改变阻止盲用旧游标；意外异常只存固定类别，避免把敏感响应写入公开结果。
- 当前是串行的有限验证器：页数预算默认100，到上限为 partial，可继续；没有生产任务租约、取消、自动退避调度、真正 full/latest 多运行历史或游标失效重扫。不能直接接真实采集器便称完整任务系统。
