# 小红书最近窗口订阅：当前正式目标（2026-09-30）

用户正式调整 P0，替代 v2/v3 的首次全历史要求。这是产品目标，不是 Demo 限制。公众号继续暂缓；双平台总项目没有通过真实验收。

## 产品与验收合同

提供博主主页链接 → 识别稳定作者 ID → 后台 HTTP 核验作者 → 用户确认订阅 → 首次同步当前最新第一页 → 保存新作品的标题、正文、发布时间、图片、存在的视频及数据库关联 → 手动或定时刷新最新第一页 → 按单个、所选或全部已确认订阅作者本地导出。

- `xhs_http` 正式模式为 `recent_window`。现有来源请求 `num=30`，每轮只读第一页，最多接受 30 条；来源不足 30 条就保存实际返回量，绝不补第二页。空页、身份错配、重复 ID 或超过预算的异常响应停止。
- 首次同步与刷新均先用平台、稳定作者 ID、稳定作品 ID 去重。已存在作品不重新读取详情、不下载附件、不覆盖已有正文或媒体；新作品加入持久任务后逐篇归档。列表已观察标题/发布时间变化只记差异，不推断正文更新成功；来源不能可靠识别全部修改，保留旧内容。
- 新任务在正文或媒体失败后仅恢复该任务原来的新作品，不为补引用重新扫描列表或旧历史。已保存正文和通过校验的附件复用；没有精确引用则报缺口。
- 列表窗口、正文成功、图片、视频、媒体缺口、本地导出分别计数。任务成功只证明这次窗口的新作品保存情况，不证明全历史。页面与状态显示“最近内容同步 / 当前来源窗口约30篇”。
- 两次刷新之间新增作品超过单页窗口可能遗漏；置顶及平台返回顺序也可能影响窗口。没有全历史完整、可信历史末页或永不漏篇保证。
- `full` / `author_archive` 等旧正式入口对 `xhs_http` 转入最近窗口；旧深分页任务保留证据，但不可继续。#72、7 页检查点、第 8 页、历史末页、全历史完整率和 -100 根因研究退出当前 P0，不继续排查。
- 导出只读本地资料，没有平台请求。导出单个、所选、全部已确认订阅作者；单个、所选和全部的新导出均限已核验、已确认且仍订阅的作者；取消或待确认作者不进入新导出。已生成归档仍可本地阅读。

## 本轮安全与交付

本轮只离线实现、合成回归、文档和 Git 非强推同步。禁止小红书真实列表/详情/媒体/来源验证、浏览器自动化、登录或会话更新；禁止运行 #72/#74、部署或生产重启、操作 WeWe。暂停仍持久化且默认拒绝，定时刷新代码存在但当前不能实际联网。新产品范围不解除账号安全限制。

生产两库、媒体、旧游标与手工笔记本轮不写入；测试只用临时合成工作区，出口拦截防止外连。新增独立 `recent_window_observations` 列表差异观察表；旧库初始化前使用 SQLite backup 并验证 quick_check，作品/附件原表与资料目录不改。已有安全备份及 961 附件核验是上轮证据，不能说本轮又执行过。源码完成不代表已安装包更新，也不代表真实平台闭环完成。

## 下一次最小真实验证计划（未批准、未执行）

目标仅一个用户明确指定作者，核对**新取第一页原返回顺序的前三篇**。生产窗口仍是最多 30 篇；前三篇只是此次验收样本。旧 #72 样本不自动当作当前最近前三篇。

开始前仍须明确：该 HTTP 来源的访问依据和非规避边界；账号提示/限制的适当处理及实质条件变化；仅该账号本机私有会话的凭据范围；离线结果经审阅；生产数据库一致性备份及旧正文、附件校验。当前 `xhs_http` 需要用户合法登录会话文件（`a1` / `web_session`）；缺少或失效则停止。本轮不创建、不更新、不读取真实凭据，禁止用自动化浏览器取得会话，不绕过验证码或账号限制。不能因时间过去、登录、降频或页面能打开而解除暂停。

建议一次获准验证的硬预算：**最多 16 个 HTTP 请求**，串行，无自动重试、无重定向跟随、无下一页、无定时器、无正常 30 篇归档任务连带运行：

1. 1 次最新第一页列表，核对全部返回项作者 ID，保留前三篇 ID、标题与顺序；不另发作者健康检查或重复核验列表。
2. 3 次前三篇详情，严格核对每篇作品 ID、作者 ID、标题、正文、发布时间及媒体归属；详情作者核验复用该响应，不能加探测请求。
3. 最多 12 次这三篇的可获取图片/视频下载；实际需求是 `M` 个尚未本地验证的附件，请求总数为 **4 + M（M ≤ 12）**。已有文件只做本地大小/哈希/归属核验。媒体数量目前未知，不能预先声称一定 9 次或其他精确实际值。若 `M > 12`，在媒体阶段前停止并报告新的确切预算，不能截取 12 件宣称媒体验收通过。若出现重定向，直接停止，不让跳转扩大请求数。

任何业务失败（含 -100）、HTTP 拒绝、验证码/平台验证、登录失效、身份错配或异常响应立即停止，不自动补取或切来源/账号/IP。剩余请求全部取消，保留原资料与脱敏现场，重新保持暂停。三篇只有全部所需媒体均已核验且内容有原响应依据才算匹配通过；本地一致性不能冒充官方匹配。

当前硬拒绝代码没有运行时解锁入口；下一次实施需按已明确批准的单次预算设计受控执行，禁止全局解除保护或借旧工作树绕过。该计划不授权后续全历史或持续联网。上线验收仍须确认正常 30 篇窗口和后续新 ID 刷新；单次前三篇匹配不能替代所有窗口媒体已保存的证据。
