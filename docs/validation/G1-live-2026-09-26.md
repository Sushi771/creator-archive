- XHS-A：1张，959×1280，126,810字节。
- XHS-B：2张，1080×1443，分别151,216与121,232字节（按作品图序）。轮播 DOM 有首尾克隆，直接按第一个 `img` 去重会颠倒顺序；依据非克隆 slide 的 `data-swiper-slide-index` 校验图序。私有文件名按下载顺序保留，manifest 的 `position` 才是作品图序。
- 两个输入作品是图文，不把封面当视频。从 XHS-A 主页带播放标记的作品进入详情，作者 ID 一致。页面视频720×960，在线播放走到结束；页面展示时长约10.1秒。
- 浏览器资源清单提供真实MP4资源地址；资源打包失败（fetch错误），之后对同一已观察到的CDN资源做独立HTTP验证，无Cookie。文件总长332,498字节，最高原画质/作者上传原文件未验证。
- 文件续传：独立Python进程请求 `bytes=0-65535`，收到 `206` 与总长332,498；写入并fsync `.part` 后 `os._exit(23)`。另一进程从持久文件长度65,536发起Range请求，收到 `bytes 65536-332497/332498`，仅下载余下266,962字节；前缀哈希不变，长度、MP4容器标记校验后rename成完整文件。PowerShell包装命令返回非零，内部终止码记为23。
- 离线文件播放：临时回环服务只提供本地MP4和无外部依赖的验证HTML，使用随机路径且不列目录；CSP只允许同源媒体。Edge实际解码为720×960、9.984603秒，最终 `ended=true`、`readyState=4`、`error=null`。原网页MSE时长与该MP4时长分别记录，未声称二者元数据完全一致。没有关闭整机网络，也没有把在线播放当离线文件播放。

**该实测只证明这一视频资源支持文件字节续传。** 不是作者分页恢复、过期签名恢复、全部视频兼容性或生产下载器通过。成功图片没有在视频恢复过程中重新下载。
